# 三顺官网

三顺展具金属制品有限公司官网，使用Next.js 14 + Tailwind CSS + next-intl开发。

## Git仓库地址

```
https://github.com/sanshunzhanju/sanshun-guanwang.git
```

## 技术栈

- Next.js 14
- React 18
- Tailwind CSS
- TypeScript
- next-intl (国际化)

## 项目结构

```
├── src/
│   ├── app/          # App Router 页面
│   ├── components/   # React 组件
│   ├── data/         # 模拟数据
│   ├── i18n/         # 国际化配置
│   ├── styles/       # 全局样式
│   └── middleware.ts # 中间件
├── public/           # 静态资源
└── package.json      # 项目依赖
```

## 开发命令

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm run start
```
